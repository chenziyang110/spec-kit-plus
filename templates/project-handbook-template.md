## High-Value Capabilities

- **Scenario-first E2E**: When explicitly invoked, `sp-e2e` / `spx-e2e`
  challenges operation assumptions and derives abnormal, boundary, state,
  external-event timing, concurrent, recovery and cross-feature cases before
  execution. Desktop/mobile visual-model testing is first-class and does not
  require a browser runner or test file. Preserve exact case/checkpoint IDs,
  original observations, independent effect readback, failed/skipped/blocked
  cases and cleanup evidence. Test Design is an optional read-only source;
  E2E never substitutes for integrated Review or human Accept. Its Python
  helpers are stateless test-asset utilities, not workflow mutation APIs.
